# Playwright Passport Project

This is the new Playwright + TypeScript project for your Passport automation.

## First steps

Open a terminal in this folder:

```powershell
cd "C:\Users\Dell Home\git\TestOV\Automation_Tsunami\playwright-passport"
```

Install packages:

```powershell
npm.cmd install
```

Install the browser:

```powershell
npx.cmd playwright install chrome
```

List the tests:

```powershell
npx.cmd playwright test --list
```

Run the tests:

```powershell
npm.cmd test
```
